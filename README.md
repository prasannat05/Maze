Maze Game  
A simple maze escape game built using HTML, CSS, and JavaScript where the player have to reach the exit block

How to Play:  
- Use W/A/S/D or Arrow keys to move  
- Reach the green EXIT block to finish the level  
- Each level increases the maze size  
- Timer tracks your completion time  
- Best time per level is saved locally  
- Touch controls supported for mobile (swipe to move)

Features:  
- Procedurally generated maze  
- Smooth animations and transitions  
- Level progression with increasing difficulty  
- Responsive design  
- Local storage high score tracking per level
